The quality check does **not pass robustly across attempt pools**. A genuine solver refinement reduces reconstruction stress on both trees, but its aggregate gain is smaller than the three-seed spread when normalized against the genuine quality variants. Weaker methods do score lower. More seriously, four tested shortcuts score above the stored reference: copying the input distances, supplying unrelated hierarchy coordinates, replacing the fixed data generator, and trading away the asymmetry constraint. Two of these reach every scored metric's optimum.

The copied-answer shortcut uses only the public graph generator: the entire target matrix is available as the embedding input. Hiding source rows in the scoring code therefore does not hide answers. Access to these distances is appropriate for transductive MDS; accepting an unconstrained copy as a low-dimensional embedding is the scoring failure. The separately supplied hierarchy field creates another route to gain without any improvement to the evaluated distances.

The generator shortcut changes an asset the test treats as fixed, rather than changing evaluator code. As a cross-check, its artifacts were scored again after restoring the original generator: stress rises to `0.045007 / 0.048192`, worse than the reference, and MAP falls to `0.270739 / 0.607385`. Those results are in [scores_true_task.json](redteam/shortcut_fixed_generator/scores_true_task.json). The perfect test scores came from moving the target.

The main repairs indicated by these runs are to bind the scored distances to a verified two-dimensional representation, derive hierarchy information from that same representation, fix the benchmark assets used by hidden evaluation, and make required constraints determine eligibility. Missing experiments and nonfinite values also need explicit rejection. The benchmark should distinguish scientifically different neighbour sets from arbitrary ordering within the many tied graph distances, and it should record reference scores from the exact shipped artifacts. These are findings for the next iteration; this audit does not modify the gym's scoring.
