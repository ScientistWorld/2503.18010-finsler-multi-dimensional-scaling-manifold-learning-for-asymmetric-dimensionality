# Scientist Constraints

## Data
Use the provided directed binary-tree generator with parent-to-child edge weight `0.5`, child-to-parent edge weight `1.5`, and same-depth directed weights `0.1`. The primary benchmark uses depth `7`; the secondary repeat setting uses depth `5`. Do not add external graph data or change either scored graph size.

## Embedding Budget
Use two-dimensional embeddings for both scored experiments. Increasing the dimension would make the benchmark easier by adding representational capacity rather than improving the directed-distance embedding method.

## Evaluation
Report scores only through `scripts/evaluate.sh` using saved artifacts. Evaluation code must not import from `method/`, and method code must not modify `eval/` metrics.

## Compliance Checklist
- [ ] The primary benchmark graph is depth 7 with the specified edge weights.
- [ ] The secondary benchmark graph is depth 5 with the specified edge weights.
- [ ] Submitted embeddings are two-dimensional.
- [ ] Scores are generated by `scripts/evaluate.sh`.
- [ ] Evaluation code does not import from `method/`.
