# Scientist Constraints

## Data
The instances are fixed by the evaluators: the paper's exact trees (`scores.json`), the visible family seeds in `eval/train/` (`scores_train.json`) and hidden instances (`scores_test.json`). Do not change graph sizes, edge-weight families or instance counts, and do not add external graph data to the scored experiments. `data/directed_tree.py` is a public copy of the generator for development; editing it does not change any score.

## Embedding Budget
Two coordinates per node and one constant drift vector of norm < 1 per instance, interpreted as `d(i -> j) = ||x_j - x_i|| + drift . (x_j - x_i)`. Higher-dimensional embeddings, per-node drifts, or distance matrices that are not induced by these coordinates are not accepted (they are rejected as invalid output).

## Running
The method must run inside the provided container without network access and embed all instances of a slice within 3600 s on one CPU. It receives only the dissimilarity matrix and a seed for each instance.

## Evaluation
Scores come only from `scripts/evaluate.sh`, `scripts/evaluate_train.sh` and `scripts/evaluate_test.sh`, which run the registered command and recompute every metric. Evaluation code must not import from `method/`, and method code must not modify `eval/`.

## Compliance Checklist
- [ ] The method is registered with a card under `outputs/` and runs from the workspace root.
- [ ] Outputs are two-dimensional coordinates plus a drift with norm < 1.
- [ ] No scored instance, size or weight family was changed.
- [ ] Scores are generated by the `scripts/evaluate*.sh` scripts.
- [ ] Evaluation code does not import from `method/`.
