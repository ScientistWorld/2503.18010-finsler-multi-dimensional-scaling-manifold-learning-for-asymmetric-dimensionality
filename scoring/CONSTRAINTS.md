# Scientist Constraints

## Data
The instances are fixed by the evaluators: the paper's exact trees and the whole Cora and Citeseer components (`scores.json`), the visible seeds in `eval/train/` (`scores_train.json`) and hidden instances (`scores_test.json`). Do not change graph sizes, edge-weight families, the citation graphs, the subgraph size or instance counts, and do not add external data to the scored experiments. `data/directed_tree.py`, `data/citation_digraph.py` and `data/citation_graphs/` are public copies for development; the evaluators keep their own copies (the graphs are checked by SHA-256), so editing them does not change any score.

## Embedding Budget
Per instance, `embedding_dim` coordinates per node (2 for the trees, 10 for the citation graphs, as given in `index.json`) and one constant drift vector of norm < 1, interpreted as `d(i -> j) = ||x_j - x_i|| + drift . (x_j - x_i)`. Other dimensions, per-node drifts, or distance matrices that are not induced by these coordinates are rejected as invalid output.

## Running
The method must run inside the provided container without network access. The evaluator stops a command after 4 hours per slice (hang guard only). The reference embeds the paper setting in about 8 minutes and the hidden slice in about 1.5 minutes on one CPU. A method receives only the dissimilarity matrix, the embedding dimension and a seed for each instance.

## Evaluation
Scores come only from `scripts/evaluate.sh`, `scripts/evaluate_train.sh` and `scripts/evaluate_test.sh`, which run the registered command and recompute every metric. Evaluation code must not import from `method/`, and method code must not modify `eval/`.

## Compliance Checklist
- [ ] The method is registered with a card under `outputs/` and runs from the workspace root.
- [ ] Outputs have the instance's `embedding_dim` coordinates plus a drift with norm < 1.
- [ ] No scored instance, graph, size or weight family was changed.
- [ ] Scores are generated by the `scripts/evaluate*.sh` scripts.
- [ ] Evaluation code does not import from `method/`.
