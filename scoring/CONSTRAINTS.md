# Scientist Constraints

## Data
Use the provided directed binary-tree generator with depth `7`, parent-to-child edge weight `0.5`, child-to-parent edge weight `1.5`, and same-depth directed weights `0.1`. Do not add external graph data or change the graph size for the primary score.

## Embedding Budget
Use two-dimensional embeddings for `directed_tree_reconstruction`. Increasing the dimension would make the benchmark easier by adding representational capacity rather than improving the asymmetric embedding method.

## Evaluation
Report scores only through `scripts/evaluate.sh` using saved artifacts. Evaluation code must not import from `method/`, and method code must not modify `eval/` metrics.

## Compliance Checklist
- [ ] The primary benchmark graph is depth 7 with the specified edge weights.
- [ ] The submitted primary embedding is two-dimensional.
- [ ] Scores are generated by `scripts/evaluate.sh`.
- [ ] Evaluation code does not import from `method/`.
